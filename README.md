# Scrabble CLI Solver

A terminal Scrabble solver featuring ANSI table formatting, length filtering, bingo calculations, and dictionary definitions.

## Installation

### Fast Install (POSIX / macOS / Linux)

```sh
curl -fsSL [https://raw.githubusercontent.com/danz-the-penguin/scrabble-cli/main/solve](https://raw.githubusercontent.com/YOUR_USERNAME/scrabble-cli/main/solve) -o /usr/local/bin/solve && chmod +x /usr/local/bin/solve
